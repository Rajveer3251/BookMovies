# BookMovies

Full-stack movie ticket booking application built with React, Vite, Express.js, and MongoDB.

## Project source
Download and extract `BookMovies-fullstack.zip` from the repository to get the complete frontend and backend source code.

## Setup
See the included README inside the ZIP archive for setup instructions, environment variables, API routes, and local development commands.

**Security:** Never commit your MongoDB Atlas URI, JWT secret, or `.env` file.
